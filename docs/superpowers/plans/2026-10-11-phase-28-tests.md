# Phase 28 — Tests : plan de réalisation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** chaque partie de SellWasl a ses tests (API, paquets, Web, mobile), avec une couverture mesurée et protégée, et une stratégie écrite.

**Architecture:** matrice des droits générée depuis les métadonnées Nest ; Vitest + Testing Library pour le Web ; Playwright sur l'application compilée et une base dédiée ; jest-expo pour les écrans du mobile ; seuils de couverture par paquet.

**Tech Stack:** Vitest 3 (coverage v8), @testing-library/react, jsdom, Playwright 1.64, jest-expo 57, @testing-library/react-native.

**Spec:** `docs/superpowers/specs/2026-10-11-phase-28-tests-design.md`

## Global Constraints

- `pnpm test` reste autonome (base Docker locale) ; `pnpm test:e2e` à part.
- Aucun test ne modifie les données de démonstration dont dépendent les autres suites sans les rétablir.
- Fusion locale dans `main`, sans push ; CI locale verte.

## Review Focus

1. La matrice ne déclenche aucune écriture (refus avant le traitement ; positifs seulement en GET).
2. Une route ajoutée plus tard est couverte sans modifier le test.
3. Les parcours Playwright ne dépendent pas d'Internet (tuiles de carte).
4. Les seuils de couverture ne font pas échouer un paquet sans tests.
5. Les écrans mobiles testés n'appellent jamais le réseau réel.
